1) Upload these files from local machine to cPanel home folder (/home/zemensjf):
- backend_build_for_cpanel.zip
- frontend_dist_for_cpanel.zip
- zemen_sacco_for_cpanel.sql (or zemen_sacco_for_cpanel.zip)
- cpanel_backend.env

2) In cPanel File Manager:
- Create backend app folder: /home/zemensjf/zemen-api
- Extract backend_build_for_cpanel.zip into /home/zemensjf/
- Move extracted backend/* contents into /home/zemensjf/zemen-api
- Ensure /home/zemensjf/zemen-api/.env exists with content from cpanel_backend.env

3) In cPanel Node.js App:
- Application root: /home/zemensjf/zemen-api
- Application startup file: dist/index.js
- Application URL: api.zemensacco.com
- Node version: 20.x (or highest LTS available)

4) In cPanel Terminal/SSH:
cd /home/zemensjf
find /home/zemensjf/nodevenv -type f -name activate
source /home/zemensjf/nodevenv/zemen-api/20/bin/activate
cd /home/zemensjf/zemen-api
which node
node -v
which npm
npm -v

5) Install dependencies and build:
npm ci
npm run build:deploy

6) Import database:
mysql -h localhost -u zemensjf_zemensjf -p zemensjf_db < /home/zemensjf/zemen_sacco_for_cpanel.sql

7) Apply schema checks/migrations:
npm run db:apply:mysql-baseline
npm run db:verify:mysql-baseline
npm run db:migrate:deploy

8) Seed only if DB is empty (skip if imported real data):
npm run db:seed

9) Restart Node.js app in cPanel panel.

10) Frontend deploy:
- Extract frontend_dist_for_cpanel.zip
- Upload extracted files to /home/zemensjf/public_html
- Ensure .htaccess has SPA rewrite rules

11) Verify:
- https://api.zemensacco.com/api/health
- https://zemensacco.com/admin/login

12) Security follow-up:
- Rotate DB password because it was shared in chat
- Update DATABASE_URL and MYSQL_MIGRATION_URL with URL-encoded new password
